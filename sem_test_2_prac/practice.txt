### Practice Prolog (eww) Questions

Write a prolog predicate called `witcher_contracts` which succeeds if witcher `X` has a contract on monster `Y`.
Dummy Data:
```prolog
monster(wyvern).
monster(leshen).
monster(kikimora).
monster(fiend).
monster(griffin).
monster(basilisk).

witcher(geralt).
witcher(vesemir).
witcher(coen).
witcher(lambert).

contract(geralt, wyvern, novigrad).
contract(geralt, leshen, velen).
contract(vesemir, kikimora, skellige).
contract(geralt, fiend, ard skellig).
contract(yen, fiend, novigrad).
contract(vesemir, fiend, ard_skellig).
contract(coen, griffin, whiteorchard).
contract(jaskier, basilisk, kaer_morhen).
```
Must Pass:
```
witcher_contracts(geralt, leshen).
true.

witcher_contracts(yen, fiend).
false.

witcher_contracts(vesemir,griffin).
false.
```

Write a predicate called `multiple_contracts' which succeeds if witcher 'X' has multiple active contracts. (same data)
Must Pass:
```
multiple_contracts(geralt).
true.

multiple_contracts(jaskier).
false.
```
Write a predicate called `witcher_without_monster' which finds  if a witcher has contracts for any monsters

```
witcher_without_monster(geralt).

witcher_without_monster(lambert).
true.
```

Write a predicate 'trainers_evolve_pokemon' that returns if two trainers have pokemon that are on the same evolution branch.
Write a predicate 'baby_pokes' that returns if a pokemon is a baby pokemon (level 1 in evolution tree).
```prolog
evolves_into(igglybuff, jigglytuff).
evolves_into(jigglypuff, wigglytuff).
evolves_into(happiny, chansey).
evolves_into(chansey, blissey).
evolves_into(cleffa, clefairy).
evolves_into(clefairy, clefable).
evolves_into(gastly, haunter).
evolves_into(haunter, gengar).

trainer(hayley, gengar).
trainer(ash, gastly).
trainer(mallow, happiny).
trainer(hayley, clefable).
```

Must Pass
```
trainers_evolve_pokemon(hayley).
true.

trainers_evolve_pokemon(mallow).
false.

baby_pokes(igglybuff).
true.

baby_pokes(gengar).
false.
```
